📊 Customer Data Analysis Project

📌 Project Overview

This project analyzes retail customer data to discover valuable business insights by combining customer demographic information with transaction history. The workflow includes data cleaning, preprocessing, feature engineering, exploratory data analysis (EDA), and customer segmentation to better understand purchasing behavior and support data-driven business decisions.

🎯 Project Objectives

- Clean and prepare raw customer and transaction data.
- Merge multiple datasets into a unified analytical dataset.
- Analyze customer demographics and purchasing behavior.
- Identify high-value customer segments.
- Discover sales trends across different cities and customer groups.
- Generate business insights to improve customer retention and marketing strategies.

🛠️ Tools & Technologies

- Programming Language: Python
- Libraries: Pandas, NumPy, Openpyxl, Matplotlib, Seaborn
- Environment: Jupyter Notebook

📂 Dataset

The project uses two primary datasets:

- Customer_Master_Data – Customer demographic information.
- Customer_Transactions – Customer purchase history and transaction records.

🔍 Project Workflow

1. Data Cleaning

- Removed duplicate records.
- Handled missing values.
- Corrected inconsistent data.
- Standardized column formats.

2. Data Integration

- Merged customer and transaction datasets.
- Verified data integrity after merging.
- Prepared the dataset for analysis.

3. Feature Engineering

- Converted date columns into proper datetime format.
- Extracted Month and Year from transaction dates.
- Created analytical features for reporting.

4. Exploratory Data Analysis (EDA)

- Customer distribution analysis.
- Transaction frequency analysis.
- Spending pattern analysis.
- City-wise customer analysis.
- Gender-wise purchasing behavior.
- Sales trend exploration.

5. Customer Segmentation

- Identified high-value customers.
- Compared customer groups by city and gender.
- Analyzed purchasing patterns across different customer segments.

📈 Key Insights

- Customer purchasing behavior varies significantly across different cities.
- Certain customer segments contribute a larger share of total revenue.
- Demographic analysis helps identify high-value customer groups.
- Clean and structured customer data enables more accurate business reporting and decision-making.

🚀 Business Value

The insights from this analysis can help businesses:

- Improve customer targeting.
- Enhance marketing campaigns.
- Increase customer retention.
- Identify profitable customer segments.
- Support data-driven business strategies.
